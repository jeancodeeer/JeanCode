¿No tienes API?

Tu propia API gratis, con GPU, en tu cuenta de Kaggle (sin tarjeta):

  1. Genera una clave y guárdala:
  2. Abre el notebook en Kaggle (con tu teléfono verificado en Kaggle): Abrir en Kaggle
  3. En el notebook: Settings → Accelerator → GPU T4 x2, y en Add-ons → Secrets añade JEAN_API_KEY con tu clave.
  4. Pulsa Run All y espera 3–6 minutos.

Luego pega arriba la URL que imprime el notebook. Cada sesión dura hasta 12 horas y tu cuota de GPU (unas 30 h) se renueva cada semana; al volver a pulsar Run All la URL cambia.

                  Sobre JeanCode
                  
  
                  
    
    
    
    
    
  
                  
  
                  
    
                  
      
                  JeanCode es el cliente de los modelos Jean (Grey, Marvel y Fénix) y de otras APIs compatibles con OpenAI.
                  
      
                    
        
                  • Chat: conversación con respuestas en streaming.
                    • 
        
                  • Code (web): Jean escribe todos los archivos de un proyecto; los editas, ves la vista previa y descargas el .zip. No toca tu PC.
                    • 
        
                  • Agent (escritorio): un agente que trabaja dentro de una carpeta de tu PC.

                    Relay para APIs que bloquean la web
                    
    
                    NVIDIA, SambaNova y Z.ai rechazan llamadas desde páginas web. Si tienes un Jean-API-Generator conectado, se usa su relay solo. Si no, despliega tu propio relay gratis en Cloudflare (guía de 3 pasos) y ponlo aquí.
                    
    
                    
      
      
      
    
                    
    
                    
  
                    

  
                    
    
                    Elección automática y respaldo
                    
    
                    En el selector eliges, para cada modo (chat, code, agente): AUTO (JeanCode elige y explica por qué en la etiqueta junto al selector), un modelo concreto, o una conexión fija (el mejor modelo de esa conexión, p. ej. solo los locales). AUTO descarta los modelos caídos, los que no aceptan herramientas en el agente y los que no tienen contexto suficiente. Si el modelo no responde, JeanCode puede probar otro antes de que llegue la respuesta; nunca por errores de clave o de la petición.
                    
    
    
                    
    
    
                    Sin esta casilla, JeanCode nunca pasa solo a un modelo que cobra: solo si tú lo eliges o lo pones en tu cadena.
                    
    
                    Fénix
                    
    
                    El modelo más capaz (27B). En Kaggle cabe en las dos GPU: pon MODELOS = "fenix" en el notebook (o JEAN_MODELS=fenix con launch.py) y búscalo aquí. Responde más lento.

                      Control desde el móvil
                      
    
                      
      
                      Maneja el agente de este PC desde tu móvil (web o app de JeanCode), como Remote Control de Claude Code. Todo va cifrado de extremo a extremo con una clave por móvil. En la misma Wi-Fi la conexión es directa; para usarlo desde fuera hace falta tu Worker de Cloudflare (el de la carpeta relay/): intenta P2P y, si la red no lo deja, pasa por él (sin poder leer nada). Solo funciona con JeanCode abierto.
                      
      
      
      
                      
        
        
        
      
                      
      
                      
      
                      
      
                      
        
        
                      
          
                      Escanéalo con la cámara del móvil (abre JeanCode web) o, en la app, con PC → Escanear QR. También puedes copiar el enlace. Caduca a los 10 minutos y sirve una sola vez; al usarlo, el PC te pedirá confirmación.
                      
          
                      
        
                      
      
                      
      
                        
    
                        
    
                        Hooks del usuario
                        
    
                        Comandos que se ejecutan solos en momentos del agente, en todos tus proyectos, con el mismo formato que el settings.json de Claude Code: eventos PreToolUse, PermissionRequest, PostToolUse, PostToolUseFailure, UserPromptSubmit, Notification, Stop, SubagentStart, SubagentStop, PreCompact, SessionStart y SessionEnd. Las herramientas se llaman como en Claude Code (Bash, Read, Write, Edit…), así que tus hooks de Claude funcionan tal cual. Escribe /hooks en el agente para ver los activos. Guía y ejemplos.

                              Skills
                              
  
                              Una skill es una carpeta con un SKILL.md. El agente ve la lista y carga la que necesite.
                              
  
                                
  
                                
    
    
                                
      
      
    
                                
  
                                
  
                                Catálogo · 100 skills
                                
  
                                Elegidas de repositorios abiertos (Anthropic, Superpowers, Trail of Bits, Hugging Face y otros), con su licencia. Se descargan de GitHub al instalarlas. Instala solo las que vayas a usar: el agente ve la lista de las instaladas en cada turno.
                                
  
                                
    
    
  
                                
  
                                
                                


  
                                Plugins
                                
  
                                Un plugin agrupa skills, subagentes y comandos con el formato de los plugins de Claude Code (.claude-plugin/plugin.json). Sus skills se cargan con load_skill, sus subagentes con spawn_subagent y sus comandos se escriben como /plugin:comando. Solo se usa su texto: los hooks, servidores MCP y scripts del plugin no se ejecutan.
                                
  
                                  
  
                                  
    
    
                                  
      
      
    
                                  
  
                                  
  
                                  Catálogo
                                  
  
                                  Se descargan de GitHub al instalarlos (clon superficial; ECC tarda un poco, son miles de archivos).
                                  
  
                                  
                                  


  
                                  Automatizaciones
                                  
  
                                  Tareas que el agente hace solo, como las tareas programadas de Claude: con una expresión cron, una sola vez o a mano. Corren mientras JeanCode está abierto; si se perdió una con la app cerrada, se hace una vez al abrirla. Nadie puede aprobar nada durante una ejecución: lo que pediría permiso se deniega y queda en el historial. Solo corren los comandos que ya marcaste como «permitir siempre» en esa carpeta, y los hooks del usuario y los del proyecto en los que ya confiaste. También puedes pedírselo al agente: «cada lunes a las 9 revisa las dependencias».
