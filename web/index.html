        INFO DEL REPO

        01 — QUÉ ES

        JeanCode es el cliente gráfico de los modelos Jean v0.7 (Grey, Marvel y Fénix). Tiene dos modos en la web y un tercero en el escritorio:

        • CHAT — conversación normal con respuestas en streaming y código resaltado.
        • CODE — describes un proyecto y Jean genera todos sus archivos. Los ves en un árbol, los editas, ves la vista previa de páginas web y descargas todo en .zip. No toca tu PC.
        • AGENT (escritorio) — un agente estilo Claude Code que trabaja dentro de una carpeta de tu PC.

        03 — TU API

        1. Crea un Codespace desde Jean-API-Generator ↗.
        2. Agrega los secretos JEAN_API_KEY (puedes generarla en el splash) y HF_TOKEN.
        3. Inicia el Codespace y deja públicos los puertos 8888 (Grey) y 8889 (Marvel).
        4. Pega en JeanCode la URL del puerto terminada en /v1 y tu clave. Puedes añadir los dos puertos en AJUSTES.

        Si el Codespace está dormido, la API no responde hasta que lo despiertes; al despertar tarda unos minutos en cargar los modelos.

        04 — ESCRITORIO

        • Lee, busca y edita archivos dentro de la carpeta de trabajo que elijas (nunca fuera).
        • Ejecuta comandos de terminal; cada comando pide tu confirmación salvo que cambies el modo de permisos.
        • Lanza subagentes para dividir tareas y combina sus resultados.
        • Instala skills: carpetas con un SKILL.md que le enseñan procedimientos nuevos.

        05 — PRIVACIDAD

        JeanCode es una página estática: no tiene servidor ni base de datos. Tus mensajes van directo de tu navegador a tu propia API. La URL, la clave y el historial se guardan en el almacenamiento de este navegador; puedes borrarlos en AJUSTES.
