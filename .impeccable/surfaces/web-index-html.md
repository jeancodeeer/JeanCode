# JeanCode app shell (web + escritorio + móvil)

Scope: toda la interfaz de `web/` (splash, shell, chat/code/agent, paneles); el escritorio la reutiliza. Modo: Operate. Build path: code-led (pantalla de trabajo). Dirección fijada por el usuario: OPIUM + neobrutalismo + minimalismo funcional, negro con blanco, IBM Plex; conservar wordmark con ruido y grano.

## Direction contract

THESIS: un taller de noche, no un tablero. La pantalla es el trabajo (la conversación y el compositor); todo lo demás se retira a menús y pestañas. Rechaza el dashboard SaaS de tarjetas y el "todo con borde blanco".

OWN-WORLD: negro puro, tinta hueso #F2F1EC, gris de humo para lo secundario, líneas de estructura en gris carbón de 1px; el blanco sólido queda para la acción, la selección y el foco. Plex Sans Condensed estirada para el wordmark, Plex Sans para leer, Plex Mono solo para código, datos y atajos. Grano de fotocopia constante.

STORY: entra, conecta su API en un minuto, escribe; cambia de modo o de modelo sin buscar; ajustes y extras están a un toque pero nunca a la vista.

FIRST VIEWPORT: splash de una columna (~520px): wordmark estirado con ruido como única pieza fuerte, una frase, formulario de conexión, botón primario blanco, alternativa local como enlace. App: rail estrecho (wordmark pequeño, modos, nuevo, historial, menú "Más"), barra superior mínima (título, modelo), conversación centrada a 72ch, compositor anclado abajo con RAZONAR y enviar dentro.

FORM: dirección fijada por el usuario (no hubo sorteo). Movimiento firma: el bloque blanco "invertido" — el modo activo, el botón primario y el mensaje del usuario se marcan con inversión negro/blanco y una sombra hueca desplazada solo en la acción primaria. seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
